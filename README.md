# Minhas Tarefas

Aplicação web para organizar tarefas do dia a dia. Com ela, é possível adicionar atividades, acompanhar o que está pendente e marcar como concluído o que já foi feito.

## Funcionalidades

- Adicionar, editar e excluir tarefas
- Marcar tarefas como concluídas ou pendentes
- Filtrar tarefas por status
- Pesquisar tarefas pelo título
- Exibir a quantidade de tarefas pendentes
- Remover todas as tarefas concluídas
- Manter as tarefas salvas no navegador após fechar ou atualizar a página

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/gushop2007-a11y/lista-de-tarefas.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd lista-de-tarefas
   ```

3. Abra o arquivo `index.html` no navegador.
